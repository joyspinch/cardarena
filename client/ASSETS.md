# cardarena · 千军牌局 · 素材清单

参考 FreeKill 的技能 / 装备 / 状态驱动卡牌战斗；**仅借技能系统结构**，美术全自研，不移植任何武将立绘。

**总量**：图片 76 张 / 音频 9 个
**P0 图片**：71 张（卡面底板 6 + 符号化图标 60 + 卡背 1 + UI 4）
**参考源**：FreeKill —— 26 张武将立绘为**三国杀原作（游卡）IP**，总账判定**不可取用**；本项目只借 Lua 技能系统结构，零取用。

## 三、规格要点（本项目特有）

- 卡面底板 6 张按**稀有度**分层（512×768 竖版），底板 + 边框走**矢量程序化**，换稀有度只改色不重出图，属总账批次 4。
- 符号化图标 60 张统一 64×64，一图一符号：技能 / 装备 / 状态 / 势力各成一套同色槽，不画写实物件。
- 卡背 256×336 与卡面 512×768 比例不同，卡背单独出图，不做拉伸复用。
- 头像框 128×128 只做**边框与势力配色**，框内不放人像——人像属高风险素材，本项目一律用几何符号替代。
- 牌桌 1920×1080 是唯一一张全屏底图，纯色 + 轻纹理，属环境贴图不套描边。
- 音频格式统一 OGG Vorbis：SFX ≤1.5s 单声道、BGM 60–120s 立体声（总账 §1.2）。
- **估算**：像素画 76 张 ≈ 38–76 + SFX 8 ≈ 2.4 + BGM 1 ≈ 3 ≈ **43.4–81.4 人日**（口径：0.5–1 人日/张、0.3/SFX、0.5/loop、3/BGM）。

## 六、制作批次

- 批次 1（P0）：60 张 64×64 符号化图标、6 张程序化卡面底板、1 张卡背、4 件 UI 底板。
- 批次 2（P1）：4 个头像框、1 张 1920×1080 牌桌底图。
- 批次 3（音频）：8 个 SFX → 1 首对战 BGM。
- 可复用：图标 64×64 与 `crawler` 的物品图标走同一套描边与色槽逻辑；卡面底板程序化后可扩稀有度而不增加人力。
